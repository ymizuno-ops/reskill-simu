# ERRORS.md — 失敗ログ

> **ルール**: 次のどちらかに当てはまったら、このファイルに記録する。
> - **エラー**: 同じアプローチが 2 回以上失敗した
> - **設計漏れ**: 実装中・レビュー・運用のいずれかで、設計時の考慮不足が見つかった（1回目から記録する）
>
> **取り込み** 欄: `未`（プロジェクト横断の知見集に未取り込み）／ `YYYY-MM-DD → lessons/<名前>.md`（取り込み済み）／ `YYYY-MM-DD → topics/<名前>.md（未解決）`（防ぎ方が未確定のため未解決として取り込み済み）／ `対象外（理由）`（このプロジェクト固有で一般化できない）

## 2026-10-05 — CatBoost の出力先 tmp/ が無い環境で学習が失敗する状態でマージした

**種類**: 設計漏れ
**何が起きたか**: PR #2 で CatBoost の出力先を `tmp/catboost_info` に変えたが、`tmp/` は git の管理外のため、clone 直後の環境にはない。この状態で学習すると `Can't create train working dir` で失敗する（レビュー時の合成データでの学習で発覚）。
**原因**: 出力先の変更時に、親ディレクトリが存在するかを確かめなかった。`data/` などがない環境のため、学習は実行せず、起動確認だけで済ませた。
**対策**: `CatBoostWrapper.fit` の冒頭で `os.makedirs(CATBOOST_TRAIN_DIR, exist_ok=True)` を実行する。
**教訓**: git の管理外のディレクトリへ出力先を変えるときは、そのディレクトリを作る処理を同時に入れ、空の環境で実際に1回出力して確かめる。
**取り込み**: 未

## 2026-10-06 — 現在の年齢に 65 歳を入れるとシミュレーションが IndexError で落ちる

**種類**: 設計漏れ
**何が起きたか**: サイドバーの年齢は 65 歳まで入力できるが、`simulate` の転職後の推移は「65 歳以降は前年の値 × 0.97」で計算するため、初年度から 65 歳だと前年の値がなく `careerChange[-1]` で IndexError になる（コーディング規約適用のリファクタ中に、変更前のコードでも再現することを確認した）。
**原因**: 入力欄の上限（65 歳）と、シミュレーションが前提にする「初年度は退職年齢未満」という条件を、設計時に突き合わせていなかった。
**対策**: サイドバーの年齢の上限を `RETIREMENT_AGE - 1`（64 歳）にした（`src/ui/sidebar.py` の `AGE_INPUT`）。
**教訓**: 入力欄の範囲を決めるときは、その値を受け取る計算の前提条件（前年の値が必要、など）の境界値で 1 回動かして確かめる。
**取り込み**: 未
